# E5 — Freemium Bots

**One-liner:** a free bot everyone can use, premium features behind Stars — like B2 but a whole product, not one app.

## What it is
A useful bot that's free (so it spreads), with paid extras unlocked by Stars: e.g. a quiz bot (free daily, premium = unlimited), a note-taking bot, a group games bot (free games, premium = extra game modes). The free tier IS the marketing; the Stars pay for the premium tier. Same rail as B2 — official, policy-safe.

## Money flow
- **Who pays:** a small slice of heavy users (usually 2–5% convert to paying).
- **How much:** Stars per unlock, or a Stars subscription for all premium.
- **How often:** recurring for subscribers; per-unlock for impulse buyers.

## Pipe test
- **Who owns the pipe:** we own the bot and its users. Telegram owns the Stars rail (official, safe).
- **Day-400:** the user base is ours; the rail can't be cut.

## Build steps
- [ ] Pick a bot with *daily* usefulness (group game bot, quiz bot, habit tracker — daily return = the traffic engine)
- [ ] Build the free core (I do it)
- [ ] Add 2–3 premium features behind Stars
- [ ] Launch, invite first users from groups you know
- [ ] Watch the free→paid conversion; tune the price of premium

## Traffic engine
- Free = shareable; every group that adds the bot spreads it
- Daily use = the habit loop that keeps it alive
- The share moment: "I scored 4/5 today" style posts inside the bot

## Hermes sustain role
- Build + run the whole thing
- Premium feature development (what do free users beg for? that becomes premium)
- Conversion tracking and pricing experiments
- Daily content if the bot is content-based (quizzes, games)

## Launch speed
3–4 weeks to launch, months to meaningful Stars.

## Risks
- 2–5% conversion means you need real user numbers first — free tier must be genuinely good
- Don't paywall the core loop; paywall the *extra*, or users leave

## First 3 moves
1. Choose the bot category (group game bot = best spread).
2. I build the free core.
3. Pick the first 2 premium features and launch.
