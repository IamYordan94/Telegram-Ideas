# I3 — Business Directory

**One-liner:** a Telegram directory of local services — businesses pay a small monthly fee to be listed.

## What it is
A channel/bot that lists local services by category ("Amsterdam Services": plumbers, barbers, dog walkers, movers, cleaners). Businesses pay €5/month for a listing + featured spot; locals use it as the "who do you recommend" answer. Simple, boring, works. The listing itself becomes the habit: "check the directory" is a real behavior when it's the best list in town.

## Money flow
- **Who pays:** local service businesses.
- **How much:** €5–15/month per listing, featured = extra, "top of category" = extra.
- **How often:** monthly recurring. 100 listings = €500–1,500/month.

## Pipe test
- **Who owns the pipe:** the directory + the audience are ours. Telegram hosts it.
- **Day-400:** listings renew automatically if locals actually use it — the directory is the moat.

## Build steps
- [ ] Pick the city/area + categories (start with 3 categories you know: e.g. cleaning, moving, handyman)
- [ ] Build the directory bot (browse by category, business info, contact button) — I do it
- [ ] First 20 listings FREE (businesses you know personally or walk into) — a full directory sells itself
- [ ] Grow locals: post in local groups, share cards, "the answer to 'who do you know'" posts
- [ ] When the directory is visibly useful, switch to paid: existing businesses pay to stay, new ones pay to join
- [ ] Monthly renewal reminders via bot (I run it)

## Traffic engine
- Locals join to find a service → they stay for the next time they need one
- Every "who can fix my..." question in a local group = a free ad for the directory
- Businesses tell other businesses ("you should be in it")

## Hermes sustain role
- Build + run the directory bot
- Keep listings fresh (hours, prices, dead businesses removed)
- Renewal chasing via bot messages
- Monthly stats: which categories get searched (grow those)

## Launch speed
2–4 weeks to a working directory; months to meaningful recurring income.

## Risks
- Chicken-and-egg again: needs businesses AND users. The free-20-listing seed breaks it.
- Dead listings kill trust — monthly freshness check is non-negotiable.
- Start small: one city, 3 categories. Don't build "all of NL".
