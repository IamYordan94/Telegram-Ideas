# E1 — Freelance Bot Development

**One-liner:** build custom Telegram bots for businesses, get paid per project. I do ~90% of the work; you sell.

## What it is
Local businesses need bots and don't know how to get them: a barbershop wants booking, a restaurant wants order-taking, a gym wants class reminders. You sell the project, I build it, we deliver together. This is a *service business* — the client relationship is the asset, and that's yours.

## Money flow
- **Who pays:** small businesses (€500–3,000 per bot is normal for custom work).
- **How much:** fixed project price, plus optional €15–50/month maintenance retainer after delivery.
- **How often:** per project; 2–4 projects/month is a real income.

## Pipe test
- **Who owns the pipe:** WE own the client relationship. Telegram hosts the bot but the client pays us, not Telegram.
- **Day-400:** clients renew, refer, upgrade. Nothing gets cut — this is a real business.

## Build steps
- [ ] Build 2 portfolio bots (booking bot, FAQ/support bot) we can show prospects
- [ ] Define the offer: "Booking bot — fixed price, live in 2 weeks" (one page, plain Dutch)
- [ ] Prospect: walk-in businesses near you, shops you know, local Facebook groups — *you* do the talking
- [ ] Deliver: I build, you demo, client pays
- [ ] Sell the maintenance retainer with every project (recurring income)

## Traffic engine
- Referrals — one happy barbershop tells the barbershop next door
- A simple portfolio channel with the 2 demo bots
- Local business groups (physical world advantage — you can literally walk in; online devs can't)

## Hermes sustain role
- 90% of the building (you review before demo)
- Hosting, fixes, feature requests after delivery
- Client support answers (bot answers first, I handle the rest)
- Quote preparation: I draft the scope + price, you negotiate

## Launch speed
2–4 weeks to first client (build 2 demos, then sell).

## Risks
- Scope creep: client keeps asking for "one more thing". Fix: fixed price = fixed scope, changes = extra.
- Hosting/maintenance responsibility never ends — that's why the retainer exists.
- You must actually sell — the pipeline dies if you don't talk to businesses. I can't replace that.

## First 3 moves
1. Pick the 2 demo bots.
2. I build them.
3. You visit the first 5 local businesses with the pitch.
